# 句模系统

一个练英语口语的私人工具。方法论：不背单词，建「句模」——一个高频话题下 6 个问题 × 每问 2 个母语者长句 = 12 个观点，攒够多个句模后跨话题拆借，答题从现场创作变成挑模块。

## 本地打开

双击 `index.html` 即可（无需服务器、无需联网）。

## 上线到 GitHub Pages（3 步）

1. 在 GitHub 新建公开仓库（建议名字 `sentence-pattern`），把本目录下**所有文件和文件夹**上传：
   - `index.html`
   - `assets/`（含 css 与 js）
   - `seed/`（原始语料留档，可选）
2. 进入仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，Branch 选 `main`，目录选 `/ (root)`，保存。
3. 等约 1 分钟，访问 `https://<你的用户名>.github.io/sentence-pattern/` 即可。手机浏览器打开同一个网址也能用。

## 重要：数据只存在浏览器里

所有学习数据存在**你打开页面时那个浏览器**的本地存储里，**不会自动同步、不会上传**。

- 换设备 / 换浏览器 / 清缓存 = 数据不通、可能丢失
- 请定期到「数据」页点 **导出 JSON 文件**；换设备时用 **备份码** 粘贴恢复
- 录音文件不进备份，只留在本机

## 内置内容

20 个句模 × 6 问题 × 2 句 = **240 句**（A 原句 101 / B 改编 92 / C 仿写 47）：
城市、食物、工作、电影、人际、学习、旅行、健康、科技、金钱、家庭、天气、交通、宠物、音乐、节日、社交、环境、失败、目标。

## 用法要点

- **今日**：一个按钮跑完三段（热身 → 输出练习 → 跨话题拼贴）
- **复习**：管「记不记得」，四档自评决定下次什么时候再来
- **拼贴**：抽一题 + 给两个别的句模的句子当素材，答完点「借到了 / 没借到」，数据页算迁移率
- **句池**：手动录一句，或「批量摘录」——粘贴一大段英文自动切句，勾选后入池
- **数据**：导出 JSON / 备份码；设置里可调每日上限、语速、是否只练 A 类

## 文件说明

```
index.html              页面骨架
assets/css/app.css      样式
assets/js/seed.js       句模 1-5：城市 / 食物 / 工作 / 电影 / 人际
assets/js/seed2.js      句模 6-10：学习 / 旅行 / 健康 / 科技 / 金钱
assets/js/seed3.js      句模 11-15：家庭 / 天气 / 交通 / 宠物 / 音乐
assets/js/seed4.js      句模 16-20：节日 / 社交 / 环境 / 失败 / 目标
assets/js/store.js      数据存储 + 记忆排期 + 备份
assets/js/media.js      发音（浏览器语音合成）与录音（本地数据库）
assets/js/app.js        页面与训练流程
seed/corpus-a.md        原始语料留档（话题 1-5）
seed/corpus-b.md        原始语料留档（话题 6-10）
```

seed.js 会自动合并 seed2/3/4。想删掉某个话题，把对应的 seed 文件删掉、并从 index.html 里去掉那一行即可。

## 语料层级

| 层级 | 含义 | 是否进训练 |
|---|---|---|
| A | 母语者原句，未改动 | 是 |
| B | 有真实出处，为口语化做了轻微改编 | 是（可在设置里关掉，开「仅 A 严格模式」） |
| C | AI 仿写，非真实出处 | 否，仅作结构练习 |
